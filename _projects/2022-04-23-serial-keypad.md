## About
A 3D printed 2x3 Cherry MX mechanical keypad, with LED backlight using arduino pro micro.

## Links
[Parametric Model - Fusion 360 Link](https://a360.co/3xQs2pm)

[Source Code - Github Project](https://github.com/danielbibit/serial_keypad)

## Desing Notes
* Macro key pad, fully programmable (Requires platformio)
* 4 parts 3D print, fully parametric (Requires assembly)
* Virtual serial keyboard - Issue commands like 'print:Hello world\n' to the serial to type using
the arduino keyboard
